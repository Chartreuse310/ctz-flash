# 数字花园框架规划

> 一句话定位：**CTZ's WIKI 的轻量数字花园**——用这个 Obsidian 仓库存放卡片，用一个纯前端的「花园首页」把它们展示成卡片墙，点开卡片直接在模态窗口里阅读，不新开页面。

---

## 1. 参考拆解：garden.knowlats.dev

参考站是一个 Quartz 生成的传统数字花园，页面结构：

| 区块 | 内容 | 我们的取舍 |
| --- | --- | --- |
| 头部 | 站名 Little Garden + 副标题 | ✅ 保留（CTZ's Flash Garden） |
| Main Topics | 主题标签列表，可点进主题页 | ✅ 保留但简化为**标签过滤** |
| All Notes | 卡片流：标题 + 日期 + 摘要 + `#标签`，无限滚动 | ✅ 保留卡片流，轻量化为一次性加载 |
| 笔记详情 | **独立新页面**（标题 + 正文 + 反向链接） | ❌ 改为**模态窗口**，这是最大的差异化 |

参考站轻量在内容、重在建站（Quartz 需要完整构建链）；老大要的轻量化是**连建站都省掉**——仓库本身即内容源。

## 2. 技术方案：纯前端运行时渲染

- **零构建、零依赖、零后端**：一个 `index.html` + 一个 `garden.css` + 一个 `garden.js`
- 页面加载时读取仓库里的卡片 md 文件，浏览器端渲染成卡片墙
- **改卡片 = 刷新页面即生效**，不需要跑任何构建命令
- md 渲染用 CDN 引入的 marked.js（唯一外部依赖，也可以后续本地化）
- 本地预览：`python3 -m http.server` 起个静态服务即可（file:// 直接打开受浏览器 fetch 限制，需注意）

**关键问题：浏览器无法列目录**，所以需要一个「卡片清单」来告诉页面有哪些卡片。三个候选方案：

- **A. `notes/manifest.json`**：脚本生成或人工维护的卡片清单（文件名 + frontmatter 摘要），页面按清单 fetch
- **B. 索引卡片**：`notes/00-index.md` 里用列表罗列所有卡片（Obsidian 里维护自然，页面 fetch 它）
- **C. 构建期扫描**：写个小脚本扫目录生成 manifest——最省事但引入了一步「构建」

> ⚠️ **待拍板**：A / B / C 选哪个。我倾向 A（JSON 干净、易解析、可扩展），索引由一个小脚本生成。

## 3. 空间框架

```
ctz-flash/                    # Obsidian vault = 花园本体
├── index.html                # 花园首页（卡片墙 + 模态）
├── assets/
│   ├── garden.css            # 样式（轻量、衬线+等宽混排）
│   └── garden.js             # 渲染卡片墙 + 模态窗口逻辑
├── notes/                    # 🌱 卡片目录（花园的植物）
│   └── *.md                  #   每张卡片一个文件
├── discussions/              # 讨论与规划（本文件所在）
└── Welcome.md
```

与 `ctz-wiki`（主知识库，00-inbox → 90-logs 严谨消化体系）的关系：

- **ctz-wiki = 全量知识库**：文献、解析、挖掘、讨论、发现，追求完整与严谨
- **ctz-flash = 精选花园**：闪念、卡片化提炼、想被反复看见的内容；轻、美、可浏览
- 内容流向建议：ctz-wiki 里「值得反复回味」的结论 → 提炼成卡片放进 ctz-flash

## 4. 卡片规范

每张卡片一个 md 文件，frontmatter 四个字段：

```yaml
---
title: 卡片标题
date: 2026-08-05
tags: [主题a, 主题b]
summary: 一句话摘要，显示在卡片上
---
```

- 正文用 Obsidian 语法，支持 `[[wiki-link]]`——模态窗口里点击可**无缝跳转到另一张卡片**（这是模态方案比新开页更顺滑的地方：花园内漫游不出站）
- 正文长度自由：短可一句话，长可多段（模态窗口内滚动）
- 卡片内容风格建议：**一段见解 / 一条闪念 / 一个提炼**，而非长篇论述

## 5. 交互设计（模态方案）

- 首页：顶部站名 + 主题标签过滤条 + 卡片网格（瀑布流）
- 点卡片 → 居中模态窗口：标题、日期、标签、全文
- 模态内 `[[链接]]` 可点击 → 模态内容切换（支持返回）
- 关闭：Esc / 点背景 / 关闭按钮
- 标签过滤：点标签 = 只看该标签的卡片
